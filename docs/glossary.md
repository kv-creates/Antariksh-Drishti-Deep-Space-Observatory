# 📖 Glossary

- **Antariksh (अंतरिक्ष)** — space; **Drishti (दृष्टि)** — vision
- **SAA** — South Atlantic Anomaly, high-radiation zone
- **BLS** — Box Least Squares periodogram
- **SNR** — signal-to-noise ratio
- **Slew** — telescope repoint gap (5 min here)
- **H-R diagram** — luminosity vs temperature scatter
