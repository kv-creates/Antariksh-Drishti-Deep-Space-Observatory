# 🔒 Security Policy

## Supported

| Version | Supported |
|---------|-----------|
| 1.3.x   | ✅ |
| < 1.2   | ❌ (upgrade) |

## Reporting

Do not open public issues for vulnerabilities. Email kv-creates@github.com with repro + impact. Expect ack in 72 h, fix + advisory ASAP.

## Scope

`src/api.py` input validation, dependency pins in `requirements.txt`. No secrets are committed (see `.gitignore`).
